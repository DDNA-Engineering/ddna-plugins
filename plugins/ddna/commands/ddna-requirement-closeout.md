---
description: "Close out a DDNA requirement: find gaps, ask for missing evidence, and draft reviewable proposals."
---

Use DDNA MCP to close out a requirement.

1. Read the target requirement with `ddna_requirement_get`.
2. Identify missing profile fields, evidence, verification method, acceptance criteria, conflicts, and open Requirement IDE questions.
3. Ask concise follow-up questions when evidence is missing.
4. Use Requirement IDE tools to create reviewable proposals.
5. Do not apply a proposal unless the user explicitly approves that existing proposal.
